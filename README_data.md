README for data.csv

The figure is derived from Figure S2B, which shows the fraction of frameshifts and in-frame mutations from a deep sequencing analysis of lentiCRISPR-modified EGFP genes for each of the 6 sgRNAs. 

For all six sgRNAs, the corresponding data are distributed between frameshift and in-frame mutations. The data are presented in percentage form and fraction form. 

The dataset has 6 rows and 5 columns (6 x 5), with the first column containing the number of the sgRNA. The second and third columns are the percentages of frameshift and in-frame, whereas the fourth and fifth are the fractions of frameshift and in-frame, respectively.
